8.3 Computing the numerical solution of a single PDE

Let \(c=c(x,t)\).

Suppose that we want to solve the PDE

\[ \frac{\partial c}{\partial t}=D\frac{\partial ^ 2 c}{\partial x ^2} \]

on the domain \(x\in[0,L]\) with \(t\in[0,T]\).

The initial condition is \[ c(0,x)=\frac{c_0}{1+e^{\gamma (x-L/2)}} \] where \(D, c_0, \gamma \in \Re^+\).

At \(x=0\) we fix the density to be \[ c(0,t)=c_0. \] At \(x=L\) we impose a no-flux condition, i.e. \[ J_{x=0}=-D\frac{\partial c}{\partial x}\bigg|_{x=L}=0 \implies \frac{\partial c}{\partial x}\bigg|_{x=L}=0. \]

We will use the finite difference method.

  1. Discretise the independent variables

    Let \(x_i=i\Delta x\) where \(i=0,..,N_x\). Choose \[ N_x \Delta x=L \implies \Delta x = \frac{L}{N_x}. \]

    Similarly, discretise time such that

    \(t_j=j\Delta t\) where \(j=0,..,N_t\). Choose \[ N_t \Delta t=T \implies \Delta t = \frac{T}{N_t}. \]

  2. Discretise the dependent variable

    Let \(c_{j,i}\) represent the solution at the \(i^{th}\) spatial position and \(j^{th}\) time point.

  3. Approximate derivatives in the PDE using finite differences

    Using an explicit method, the first order time derivative is approximated by

    \[ \frac{\partial c}{\partial t}= \frac{c_{j+1,i}-c_{j,i}}{\Delta t}. \]

    The second order spatial derivative is approximated by

    \[ \frac{\partial^2 c}{\partial x^2}= \frac{c_{j,i-1}-2c_{j,i}+c_{j,i+1}}{\Delta x ^2}. \]

  4. Interior points in the spatial domain

    For \(0<i<N_x\) the PDE can be expressed as

    \[ \frac{c_{j+1,i}-c_{j,i}}{\Delta t} = D\frac{\partial^2 c}{\partial x^2}= \frac{c_{j,i-1}-2c_{j,i}+c_{j,i+1}}{\Delta x ^2} \]

    Note that terms involving time \(j+1\) only appear in one position. To obtain an iterative scheme rearrange such that \[ c_{j+1,i}=c_{j,i} + \nu \left(c_{j,i-1}-2c_{j,i}+c_{j,i+1}\right) \]

    where

    \[ \nu=\frac{D \Delta t}{\Delta x ^2}. \]

  5. Boundary conditions

    At \(x=0\) the boundary condition is that \(c=c_0 \forall t\). In the discretised system this is represented by \[ c_{j,0}=c_0 \forall j. \]

    At \(x=L\) we need to impose the no-flux condition. Consider the second derivative \[ \frac{\partial^2 c}{\partial x^2} = \lim_{\Delta x \rightarrow 0} \frac{\frac{\partial c}{\partial x}\bigg|_{x\rightarrow L ^+}-\frac{\partial c}{\partial x}\bigg|_{x\rightarrow L ^-}}{\Delta x}. \]

    Now impose the boundary condition at \(x=L\), i.e. \[ \frac{\partial c}{\partial x}_{x\rightarrow L^+}=0. \]

    Hence the Laplacian term can be represented by

    \[ \frac{\partial^2 c}{\partial x^2} = \lim_{\Delta x \rightarrow 0} \frac{-\frac{\partial c}{\partial x}\bigg|_{x=L^-}}{\Delta x}= \frac{c_{j,i-1}-c_{j,i}}{\Delta x ^2}. \]

Note

# Boundary condition

So the update rule is \[ c_{j+1,i}=c_{j,i}+\nu (c_{j,i-1}-c_{j,i}), \quad i=N_x. \]

8.4 An implicit method

Here we consider using an implicit method. The key idea is that the time derviative is approximated using a backwards derivative.

For \(0<i<N_x\) the PDE can be expressed as

\[ \frac{c_{j+1,i}-c_{j,i}}{\Delta t} = D\frac{\partial^2 c}{\partial x^2}= \frac{\partial^2 c}{\partial x^2}= \frac{c_{j+1,i-1}-2c_{j+1,i}+c_{j+1,i+1}}{\Delta x ^2} \]

To update at time \(j+1\) we must now simultaneously solve for all discretised spatial points.

Let the vector \(\mathbf{c}_j\) represent the solution vector a the \(j^{th}\) time point. The iterative scheme can be written as

\[ A\mathbf{c}_{j+1}=\mathbf{c}_j \] where \(A\) is a tridiagonal matrix given by \[ A= \begin{pmatrix} 1 & 0 & 0 &0 & 0 ... & 0 \\ 0 &-\nu & 1+2\nu &-\nu & 0 & . . . & 0 \\ 0 & 0 &-\nu & 1+2\nu &\nu & . . . & 0 \\ &.& .& .& .& . &. & .\\ 0 & 0& 0 & 0 & 0 &-\nu & 1+2\nu & -\nu \\ 0& 0 & 0& 0 & 0 & 0 &-\nu & 1+\nu \\ \end{pmatrix} \]

The boundary conditions are represented by the first and last rows in the matrix \(A\).

After computing A and calculating its inverse the solution can be computed using a matrix multiplication

\[ \mathbf{c}_{j+1}=A^{-1}\mathbf{c}_j \]

When solving nonlinear reaction diffusion equations, it is common to use a semi implicit method. The Laplacian is approximated implicitly whilst the nonlinear reactions are treated explicitly.

9.3.1 One spatial dimension

We want to solve the reaction diffusion problem \[ \begin{aligned} \frac{\partial u}{\partial t} & = \gamma f(u,v) + \nabla^2 u, \\ \frac{\partial v}{\partial t} & = \gamma g(u,w) + d \nabla^2 v, \end{aligned} \]

9.3.1.1 Conditions for DDI

For DDI we need the Turing conditions being derived in lectures to hold.

Consider the Jacobian \[ A=\begin{pmatrix} f_u & f_v \\ g_u & g_v. \end{pmatrix} \]

Consider also the modified Jacobian \[ \tilde{A}=\begin{pmatrix} f_u - k_2 & f_v \\ g_u & g_v-dk^2. \end{pmatrix} \]

For DDI it is required that: \[ \begin{aligned} \mathrm{tr}{A}&<0 \\ \mathrm{det}{A}&>0 \\ \mathrm{det}{\tilde{A}}&<0 \end{aligned} \]

9.3.1.2 Implementation of numerical solution of the PDE

Discretise space and time and let \(u_{ij}\) and \(v_{ij}\) represent the solution at the \(i^{th}\) time step and \(j^{th}\) spatial step. Using a backward difference for the time derivative yields \[ \frac{u_{i,j}-u_{i-1,j}}{\Delta t} = f(u_{i-1,j},v{i-1,j})+\frac{u_{i,j-1}-2u_{i,j}+u_{i,j+1}}{\Delta x ^2} \]

We can gather terms at time step \(i\) and bring to the left-hand side. Writing in matrix form, and also considering the \(v\) equation, \[ \begin{aligned} A_u \mathbf{u}_{i} & =u_{i-1}+f(\mathbf{u}_{i-1},\mathbf{v}_{i-1})\\ A_v \mathbf{v}_{i} & =v_{i-1}+g(\mathbf{u}_{i-1},\mathbf{v}_{i-1}) \end{aligned} \]

The matrices \(A_u\) and \(A_v\) have tridiagonal stucture.

Hence the solution at the \(i^{th}\) time point can be computed as \[ \begin{aligned} \mathbf{u}_{i} &=A_u^{-1}\left(u_{i-1}+f(\mathbf{u}_{i-1},\mathbf{v}_{i-1})\right), \\ \mathbf{v}_{i}&=A_v^{-1}\left(v_{i-1}+g(\mathbf{u}_{i-1},\mathbf{v}_{i-1})\right). \end{aligned} \]

The initial condition is considered by setting \(u_{0,j}\) and \(v_{0,j}\) as required.

The boundaries are represented by the first and last spatial points (\(j=0\) and \(j=N\), respectively).

The no-flux condition can be implemented by treating the boundary points as special cases. The governing equation at \(j=0\) is \[ \frac{u_{i,0}-u_{i-1,0}}{\Delta t} = f(u_{i-1,0},v_{i-1,0})+\frac{-u_{i,0}+u_{i,1}}{\Delta x ^2} \]

A similar argument applies at \(j=N\).

Once the above problem is set up, the solution is computed via a sequence of matrix multiplications in a for loop.

## Define some functions

# Define the matrix A - represents linear algebra from finite difference method
def DefineA(nu):
  A = np.zeros((N_x, N_x))
  for i in range(N_x):
      A[i, i] = 1 + 2*nu
      if i > 0:
          A[i, i-1] = -nu
      if i < N_x-1:
          A[i, i+1] = -nu

  A[0,0]=1+nu
  A[0,1]=-nu

  A[-1,-1]=1+nu
  A[-1,-2]=-nu
  return A

def ComputeReactionRates(u,v):
  reaction_u=gamma*(a-u+(u**2)*v)
  reaction_v=gamma*(b-(u**2)*v)
  return reaction_u, reaction_v

def SetInitialConditionWithNoise():
    # Define solution matrix

    u=np.zeros((N_t,N_x),dtype=float)
    v=np.zeros((N_t,N_x),dtype=float)

    init_noiseStr=0.01
    u[0,:]=(a+b)*np.ones_like(x)+init_noiseStr*np.random.uniform(low=-1.0, high=1.0, size=(N_x,))
    v[0,:]=b*(1/(a+b)**2)*np.ones_like(x)+init_noiseStr*np.random.uniform(low=-1.0, high=1.0, size=(N_x,))

    return u,v

    # Define solution matrix

    u=np.zeros((N_t,N_x),dtype=float)
    v=np.zeros((N_t,N_x),dtype=float)
    
    u[0,:]=np.cos(n*np.pi*x/L)
    v[0,:]=np.cos(n*np.pi*x/L)

    return u,v

    # Build sparse matrix for implicit scheme
    # Stability parameters
    rx = D*dt/dx**2
    ry = D*dt/dy**2    
    N = Nx*Ny  # Tot. num. grid points
    
    # Construct the sparse matrix
    diagonals = [rx, rx, ry, ry]
    offsets = [1, -1, Nx, -Nx]
    A = diags(diagonals, offsets,shape=(N,N), format="csr")
    
    # Loop over left and right boundaries of domain to deal with edges
    for left_bdy in range(Nx,Nx*(Ny-1),Nx):
        A[left_bdy,left_bdy-1]=0.0
        right_bdy=left_bdy+Nx-1
        A[right_bdy,right_bdy+1]=0.0

    # corners
    A[Nx-1,Nx]=0
    A[Nx*(Ny-1),Nx*(Ny-1)-1]=0

    # Ensure Neumann boundary condition: Adjust diagonal elements so each row sums to zero
    A = A.tolil()
    for i in range(N):
        row_sum = A[i,:].sum()
        A[i, i] =-row_sum  # Adjust diagonal to enforce sum zero
    A = A.tocsr()
    return A

def ComputeReactionTerms(u,v):
    reac_u=gamma*(a-u+(u**2)*v)
    reac_v=gamma*(b-(u**2)*v)
    return reac_u,reac_v

def SetInitialConditions(x,y):
     # Initialize solution

    rand_noise_fact=1.0
    u[:, :]=(a+b)*np.ones_like(X)+rand_noise_fact*np.random.uniform(low=-1.0, high=1.0, size=(X.shape))
    v[:, :]= b*(1/(a+b)**2)*np.ones_like(X)+rand_noise_fact*np.random.uniform(low=-1.0, high=1.0, size=(X.shape))
    u = u.flatten()
    v = v.flatten()
    return u,v

def diffusion_2d_implicit(Lx, Ly, Nx, Ny, T, Nt, D_u,D_v):
    """
    Solves  2D reaction diffusion equation using an implicit, Crank-Nicholson finite difference scheme.
 
    """

    # Spatial and temporal grid
    dx = Lx / (Nx - 1)
    dy = Ly / (Ny - 1)
    dt = T / (Nt-1)
    x = np.linspace(0, Lx, Nx)
    y = np.linspace(0, Ly, Ny)

    # Set initial condition 
    u,v=SetInitialConditions(x,y)

    # Generatee matrices for implementation of FD problem
    A_u=build_A(D_u,dt,dx,dy,Nx,Ny)
    A_v=build_A(D_v,dt,dx,dy,Nx,Ny)
    I=sp.sparse.identity(Nx*Ny,format='csr')

    CN_fact=0.5 # choose to be 0.5 for Crank Nicholson, 1 for backward Euler
    LHS_matrix_u=I-CN_fact*A_u
    LHS_matrix_v=I-CN_fact*A_v
    for n in range(Nt):
        # Solve the linear system
        u_copy=u.copy()
        v_copy=v.copy()
        reac_u,reac_v=ComputeReactionTerms(u_copy,v_copy)
    
        rhs_u=u_copy+dt*reac_u+(1.0-CN_fact)*A_u*u_copy
        rhs_v=v_copy+dt*reac_v+(1.0-CN_fact)*A_v*v_copy

        u = spsolve(LHS_matrix_u, rhs_u)
        v = spsolve(LHS_matrix_v, rhs_v)

    # Reshape the solution back into 2D
    u = u.reshape((Nx, Ny))
    v = v.reshape((Nx, Ny))
    return u,v,x,y
